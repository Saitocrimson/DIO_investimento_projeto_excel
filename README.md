# DIO_investimento_projeto_excel
O objetivo do projeto é a criação de uma ferramenta de investimento que responda as 5 perguntas:
* Quanto investir por mês;
* Por quantos anos;
* Qual a taxa de rendimento mensal;
* Quanto de patrimônio vai acumular;
* Quanto vai receber de dividendos por mês.

Para responder as perguntas o usuario terá que seguir os seguintes passos:<br>
1- Inserir na tabela "Configurações" o salario e o rendimento, então irá aparecer uma sugestão de investimento de acordo com o salário;<br>
2- Na tabela "investimento mensal", 3 primeiros campos são editáveis para o usuário inserir os valores que deseja investir. Assim irá ser calculado o patrimônio e os dividendo;<br>
3- Tem na tabela "Cenário", são cenários conforme os anos;<br>
4- É possivel também ver os tipos de fundos para ajudar na tomada de decisão de aonde investir;<br>

## Respondendo as perguntas do projeto
* Como o VF e o PROCV entram nos cálculos?<br>
A função VF foi usada para calcular o patrimônio, enquanto o PROCV foi usado para apresentar os dados do tipo de investidor de forma dinâmica e  facilitar a manutenção da planilha no futuro; <br>
* Os intervalos nomeados que você criou;
As seguintes celulas teve o intervalo nomeado:<br>
   *  e12-rendimento_carteira;
   * e13 - susgestao_investimento;
   * e17 -  aporte;
   * e18- qtd_anos
   * e19 - taxa_mensal;
   * e20 - patrimonio;

* Os percentuais de cada perfil, e de onde vieram;<br>
São apenas sugestões e estão na segunda planilha, porém cada perfil soma 100%.

* O que você mudou em relação à ferramenta do Expert?<br>
Utilizei o Google planilha e mudei o banner.
